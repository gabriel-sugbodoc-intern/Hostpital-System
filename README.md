# SugboDoc Connect

Create a simple, modern, and professional Landing Page Dashboard for the existing SugboDoc Patient Portal repository.

Landing Page

Keep the existing SugboDoc branding, color palette, typography, and UI style.

Do not modify or break the existing Patient Portal functionality.

Create the landing page as the public homepage before users log in.

Add a clean navigation bar with:

SugboDoc logo/name

Home

Services

About

Contact

Login

Register

Hero Section

Add a simple healthcare-focused hero section introducing SugboDoc.

Example messaging:

“Your Healthcare, Connected.”

Provide a short description explaining that SugboDoc connects patients with healthcare providers and makes healthcare services easier to access and manage.

Add clear Get Started and Login buttons.

Services Section

Show the main services provided by the platform using clean cards/icons:

Online Appointment Booking — Book and manage healthcare appointments.

Patient Medical Records — Access encounters, diagnoses, prescriptions, laboratory results, imaging, and other medical information.

Doctor Consultation — Connect and communicate with healthcare providers.

SMS Messaging — Allow patients, doctors, and administrators to communicate through the platform.

Pharmacy / Medical Store — Browse healthcare products, select a store branch, and place orders.

Insurance Management — Browse insurance plans and submit insurance applications.

Billing & Payments — View bills, payments, and transaction information.

Queue & Appointment Tracking — Monitor appointments and relevant queue information.

How It Works

Create a simple 3-step section:

Create Your Account

Book or Access Healthcare Services

Manage Your Healthcare in One Platform

Call to Action

Add a final section encouraging users to get started:

“Take control of your healthcare today.”

Include a Create Account button.

Footer

Include:

SugboDoc branding

Short platform description

Quick links

Services

Contact information

Copyright

Requirements

Keep the design simple, clean, and healthcare-focused.

Make it fully responsive for desktop, tablet, and mobile.

Reuse existing components and styling from the repository where possible.

Do not add unnecessary features or complex animations.

Ensure Login and Register connect to the existing authentication system.

Do not modify existing Patient, Admin, Doctor, database, or API functionality unless required for the landing page.
